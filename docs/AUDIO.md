# 音 (BGM・ジングル・効果音) と、音の道具

ゲームの音は、**すべて計算で作る** (音のファイルは 1 つも無い)。楽譜 (音色 + 音符) をコードに書き、遊ぶ時にブラウザの中で波形にして鳴らす。

## 1. なぜ、この形か

* 音を作る側 (AI) は、音が聞こえない。そこで、**波形を数字と画像にして確かめられる**ように、音を「計算できる物」にした。
* 楽譜から作るので、直すのは文字を書き換えるだけ。配る容量も、ほぼ増えない (曲 7 本 + ジングル 3 本 + 効果音 18 個で、コードは約 15KB)。

## 2. しくみ

| ファイル | 役目 |
|---|---|
| `src/audio/synth.ts` | シンセ。音色 (波形・音量の変化・ビブラート・音程のすべり・フィルタ) と音符から、波形 (`Float32Array`, 32kHz モノラル) を作る。DOM に依存しない |
| `src/audio/mml.ts` | 楽譜の短い書き方 (MML ふう) → 音符 |
| `src/audio/compose.ts` | 和音の進行から、伴奏 (ベース・分散和音・ドラム) を型で作る |
| `src/audio/songs.ts` | 曲 (タイトル・ステージ選択・STAGE 1〜5) とジングル (クリア・誕生・完走) |
| `src/audio/sfx.ts` | 効果音 18 個 |
| `src/audio/analyze.ts` | 解析 (音量・頭打ち・直流・つなぎ目・高さ・明るさ・帯域・調・ぶつかり) と、文字の報告書 |
| `src/audio/eventSounds.ts` | ゲームのイベント → 鳴らす効果音 |
| `src/audio/audioManager.ts` | 鳴らす所 (WebAudio)。最初に画面を押した時から鳴る。音量は設定の「音楽 (BGM)」「効果音」(出さない / 小 / 中 / 大) |

## 3. 音の道具

### 3.1 報告書 (`npm run daw`)

`scratch/daw/` (git には入れない) に、音 1 つごとに出す:

* `report.txt` … 全部の音の一覧 (山・平均の音量・長さ) と、1 つずつの報告 (明るさ・帯域の割合・音量の流れ・つなぎ目の段差・トラックごとの音域と音量・**楽譜どおりの高さで鳴っているか**・調から外れた音・拍の頭の半音のぶつかり)
* `<名前>.png` … 上から、ピアノロール / 波形 / スペクトログラム
* `<名前>.wav` … 人が聞いて確かめる用

`npm run daw -- -t stage1` で、名前をしぼれる。

### 3.2 画面 (`/daw/`)

開発サーバーなら `http://localhost:5173/daw/`、公開版なら `/rakugaction/daw/`。

* 左: 音の一覧 (効果音は、押すとすぐ鳴る)
* まん中: ピアノロール・波形・スペクトログラム (再生位置の線つき)。下の色の札を押すと、トラックを消す / 戻す
* 右: 報告書と、曲の編集 (速さ・伴奏の型・音量・メロディ 1 小節 1 行)。「反映」で作り直す。「コードにコピー」で、`songs.ts` に貼る形で取り出す
* 画面を見ずに使う入口: `window.__daw` (`names()` / `select(名前)` / `report(名前)` / `levels()` / `edit(名前, 変更)` / `spec(名前)`)

## 4. 品質の物差し (テスト `tests/audio/audio.test.ts`)

耳の代わりに、次を自動で確かめる:

* 曲: 15〜60 秒・頭打ちなし・平均の音量が -18〜-13dB にそろう・直流なし・つなぎ目に段差なし・**調から外れた音なし**・**拍の頭の半音のぶつかりなし**・メロディとベースが楽譜どおりの高さ (97% 以上)・メロディが伴奏に埋もれない・150Hz より下にエネルギーを使いすぎない (小さなスピーカーでは出ないため)・ステージごとに調と速さがちがう
* ジングル: 2〜6 秒・ハ長調の音だけ
* 効果音: 1 秒以内・聞こえる大きさ・頭打ちなし・終わりは無音・よく鳴る音 (ジャンプ・着地・ボタン) は 0.25 秒以内・ジャンプは上がる音 / ミスは下がる音
* イベントと効果音の対応 (着地は強さで音量が変わる・ゴールが開く星だけ合図が足される)

## 5. 分かっていること・限界

* **数字で確かめられるのは「まちがっていない」ことまで**。楽しい曲か・耳ざわりでないか・ゲームの場面に合うかは、人が聞かないと分からない。作った本人は聞けていない。
* 最初の調整で見つけて直したこと (報告書の数字から): ベースが大きすぎてメロディが埋もれていた (ベース -16dB / メロディ -21dB → ほぼ同じ大きさへ)・エネルギーの 55〜77% が 150Hz より下にあった (スマホのスピーカーでは出ない音域 → ベースを倍音のある音色に変えて 21〜50% へ)・ハイハットが小さすぎた・STAGE 3 でメロディのミとベースのファが拍の頭でぶつかっていた。
* 音色は、矩形波・三角波・のこぎり波・ノイズの単純な物 (昔のゲーム機ふう)。生の楽器の音は出せない。
* iPhone は、消音 (マナーモード) のスイッチで音が出ないことがある。
* デモ (タイトルで放置) の間は、効果音を鳴らさない。
